# Predicción de Sobrecostos en Inversión Pública del Perú (MEF)

Proyecto final — **IN5306 Applied Machine Learning**, Ciclo 9 (UTEC)
Docente: Villavicencio Antunez, Jorge

Predicción del porcentaje de desviación presupuestal (sobrecosto) de proyectos de inversión pública peruana, usando datos abiertos del MEF (Invierte.pe), siguiendo la metodología CRISP-DM.

## Contenido
- `Guia_Proyecto_MEF.md` — plan de trabajo, roles del equipo y cronograma
- `Proyecto_Inversion_Publica.ipynb` — notebook principal (Google Colab)
- `Proyecto_Inversion_Publica.ipynb - Colab(ejecucion).pdf` — versión ejecutada, para referencia rápida sin abrir Colab
- `Informe_Sobrecostos_Inversion_Publica_MEF.docx` — informe en formato APA

## Datos
El dataset (~216 MB, snapshot fijo del MEF) no se sube al repositorio por su tamaño. El notebook lo descarga automáticamente desde un enlace fijo de Google Drive vía `gdown` (ver sección 2 del notebook) — así todos obtienen exactamente los mismos datos, sin depender de la API en vivo del MEF.
